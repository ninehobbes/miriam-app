# Miriam

[English](README.md) | [한국어](README.ko.md) | 日本語

Miriamは、AppleヘルスケアとAppleフィットネスに保存されたランニング記録を再発見するためのiOSランニングジャーナルです。Apple Watchのランニング履歴を期間、コース、距離別に整理し、トレンド、ランキング、受賞履歴、目標、連続達成、共有カードをひとつにまとめます。

このリポジトリはMiriamのランディングページとIssueトラッカーのみを提供します — アプリのソースコードは含まれていません。

## 動作要件

iOS 26以降が必要です。MiriamはAppleヘルスケアに保存されたランニング記録を読み込みます — Apple Watch、Appleフィットネス、またはHealthKitに記録を書き込む他のアプリで記録したランも含まれます。パワー、ケイデンス、接地時間、上下動などの詳細なランニングダイナミクスは、Apple Watchで記録した場合のみ提供されます。
