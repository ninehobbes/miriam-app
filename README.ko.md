# 미리엄

[English](README.md) | 한국어 | [日本語](README.ja.md)

미리엄은 Apple 건강과 피트니스에 저장된 러닝 기록을 다시 살펴보기 위한 iOS 달리기 기록 앱입니다. Apple Watch 러닝 기록을 기간, 코스, 거리별로 정리하고 추이, 순위, 수상 기록, 목표, 스트릭, 공유 카드를 한곳에 모아 보여줍니다.

이 저장소는 미리엄의 랜딩 페이지와 이슈 트래커 역할만 합니다 — 앱 소스코드는 포함돼 있지 않습니다.

## 요구 사항

iOS 26 이상이 필요합니다. 미리엄은 Apple 건강에 저장된 러닝 기록을 읽어옵니다 — Apple Watch, Apple 피트니스, 또는 HealthKit에 기록을 남기는 다른 앱으로 기록한 러닝도 모두 포함됩니다. 파워, 케이던스, 접지 시간, 수직 진동 같은 세부 러닝 다이나믹스는 Apple Watch로 기록한 경우에만 제공됩니다.
